# AgriGraph AI

Prototype scaffold for a county-level dairy sustainability forecasting platform.

## Scope

This repository currently contains only the project scaffold and dependency files.
Pipeline/model logic will be implemented phase by phase.

## Stack

- Backend: Python 3.11, FastAPI, PyTorch, PyTorch Geometric
- Frontend: React 18, Vite, Recharts, Tailwind CSS

## Run (later phases)

- Backend API target: `http://localhost:8000`
- Frontend target: `http://localhost:5173`
